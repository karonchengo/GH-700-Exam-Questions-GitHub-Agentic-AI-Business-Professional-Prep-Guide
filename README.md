## What Is the GitHub Certified: Agentic AI Business Professional Certification?

The GitHub Certified: Agentic AI Business Professional certification validates the ability to use GitHub and GitHub Copilot to design, automate, and optimize business workflows while maintaining effective governance and human oversight.

Unlike traditional developer-focused certifications, this credential is designed for business professionals who want to use AI-powered tools to improve everyday work without requiring deep software development or coding experience.

The certification focuses on four important capabilities:
- Using GitHub productivity platform features to organize and manage work.
- Improving productivity through GitHub Copilot.
- Designing and implementing agentic workflows and automations.
- Applying human oversight to review outputs and manage agentic workflow decisions.

The certification is particularly relevant as organizations increasingly explore how autonomous AI agents can handle multistep tasks, support business decisions, and improve operational efficiency.

## Who Should Take the GH-700 Exam?

The GitHub Certified: Agentic AI Business Professional certification is intended for business professionals who want to apply generative AI and agentic automation to improve business processes.

The primary target audience includes:
- **Product Managers:** Professionals who use GitHub and Copilot to organize product work, improve collaboration, and accelerate decision-making.
- **Program Managers:** Individuals responsible for coordinating projects, managing workflows, and improving operational efficiency.
- **Technical Project Managers:** Professionals who coordinate technical activities and use AI-powered workflows to improve project execution.
- **Business Analysts:** Specialists who identify business requirements, analyze processes, and explore opportunities for automation.
- **Business Leaders:** Professionals interested in applying AI to improve organizational productivity and business outcomes.

Candidates should have some experience using generative AI and familiarity with business projects, products, or processes. Experience with GitHub features can be helpful, but deep software development or coding experience is not required.

## GH-700 Exam Objectives and Skills Measured

According to the official GH-700 study guide, the examination evaluates four major skill areas. Understanding their respective weightings can help candidates prioritize their preparation.

| Exam Domain | Key Knowledge and Skills | Weight |
|---|---|---:|
| **1. Use GitHub Platform Features** | GitHub management policies, governance, budget controls, GitHub Projects, issues, pull requests, collaboration, and work tracking. | 20–25% |
| **2. Enhance Productivity by Using GitHub Copilot** | Copilot Chat, model selection, sessions, agents, slash commands, prompt engineering, custom agents, and agent guardrails. | 20–25% |
| **3. Design and Implement Agentic Workflows and Automations** | Agentic workflow design, workflow files, triggers, schedules, permissions, prompts, tools, skills, MCP servers, and automation implementation. | 25–30% |
| **4. Perform Human-in-the-Loop Tasks for Agentic Workflows** | Human review, approvals, rejections, revisions, escalation paths, workflow interaction, monitoring, and supervision. | 20–25% |

### 1. Use GitHub Platform Features (20–25%)

This domain focuses on using GitHub productivity features to organize business work, manage projects, and establish appropriate governance policies.

Candidates should understand how to manage GitHub environments while maintaining organizational standards, security, and operational controls.

**Key topics include:**
- Evaluating budget guardrails and token usage.
- Understanding organizational standards and secrets management.
- Applying governance, privacy, usage, and risk controls.
- Understanding Responsible AI principles.
- Recommending branch strategies and policies.
- Understanding model selection and model explainability.
- Identifying the characteristics of skills, prompts, and instructions.
- Understanding when to use Model Context Protocol (MCP) servers.
- Creating GitHub Projects and selecting appropriate templates.
- Customizing project views, columns, automation, and custom fields.
- Managing project access and permissions.
- Creating, assigning, linking, and tagging issues.
- Creating and managing pull requests.
- Linking project items and maintaining GitHub wikis.

Candidates should understand how GitHub Projects, issues, and pull requests support collaboration and work tracking across business teams.

### 2. Enhance Productivity by Using GitHub Copilot (20–25%)

This domain evaluates how effectively candidates can use GitHub Copilot to improve productivity and generate reliable business outputs.

Rather than simply generating content, candidates should understand how to select appropriate models, manage Copilot sessions, provide context, and create instructions that produce consistent results.

**Key topics include:**
- Selecting appropriate models for different business purposes.
- Starting, resuming, renaming, pinning, and archiving Copilot sessions.
- Selecting appropriate agents.
- Using @ mentions to attach tools, files, and issues.
- Understanding GitHub Copilot slash commands.
- Writing effective prompts and instructions.
- Defining response requirements, input variables, and output formats.
- Using checkpoints to revert changes.
- Creating and managing custom agents.
- Adding web search capabilities to agent instructions.
- Saving custom agents to GitHub Projects.
- Implementing agent guardrails.
- Reviewing custom agent activities.

One important preparation area is understanding the differences between GitHub Copilot Chat on github.com, the GitHub Copilot App, and GitHub Copilot CLI.

### 3. Design and Implement Agentic Workflows and Automations (25–30%)

This is the largest weighted domain in the GH-700 examination.

It focuses on identifying business processes that can benefit from agentic AI and designing workflows that allow agents to perform tasks with appropriate instructions, tools, permissions, and execution conditions.

**Key topics include:**
- Identifying business use cases suitable for agentic workflows.
- Breaking business processes into individual tasks.
- Defining decision-making criteria.
- Aligning workflows with appropriate design patterns.
- Creating agentic workflow files.
- Configuring workflow schedules, permissions, and outputs.
- Organizing workflow folder structures.
- Writing agentic workflow instructions.
- Configuring self-critique loops.
- Selecting and configuring automation triggers.
- Configuring prompts, models, and tools.
- Installing external skills.
- Creating and calling custom skills.
- Connecting agentic workflows to MCP servers to improve context.

Candidates should understand how an agentic workflow operates and how its components work together to automate multistep business processes.

### 4. Perform Human-in-the-Loop Tasks for Agentic Workflows (20–25%)

Although agentic AI can automate many activities, human oversight remains important for decisions involving business risk, quality, and control.

This domain focuses on designing review processes, managing workflow interactions, and supervising agent execution.

**Key topics include:**
- Identifying critical decision points requiring human judgment.
- Selecting appropriate agent execution modes.
- Designing escalation paths based on tool usage.
- Responding to agent requests for approval, rejection, or revision.
- Interacting with workflows while they are running.
- Resolving workflow failures.
- Stopping running agentic workflows.
- Reviewing agentic workflow outputs.
- Monitoring workflow execution and performance.
- Ensuring that agentic workflows meet business requirements.

Candidates should understand when agents can work independently and when human review, approval, or intervention is necessary.

## How to Prepare for the GH-700 Exam

The GH-700 examination covers both GitHub platform capabilities and practical agentic AI workflow design. A structured preparation strategy can help candidates develop the necessary knowledge without focusing exclusively on technical configuration.

### 1. Review the Official GH-700 Study Guide

Start with the official Microsoft Learn study guide and review all four skill areas. Pay particular attention to their weightings so you can allocate preparation time appropriately.

### 2. Practice Using GitHub Productivity Features

Become familiar with GitHub Projects, issues, pull requests, project views, custom fields, and collaboration features. Understand how these tools support work management and organizational productivity.

### 3. Explore GitHub Copilot

Practice using GitHub Copilot Chat, selecting models, managing sessions, writing prompts, and working with custom agents. Learn how instructions and context influence the quality of AI-generated outputs.

### 4. Understand Agentic Workflow Design

Focus on how to identify automation opportunities, decompose business processes, configure triggers, select tools, and implement agentic workflows. Review the role of skills, MCP servers, permissions, and self-critique loops.

### 5. Study Human Oversight and Governance

Understand how human review, approvals, rejections, and escalation paths work within agentic workflows. Pay attention to monitoring, security, privacy, budget controls, and Responsible AI practices.
